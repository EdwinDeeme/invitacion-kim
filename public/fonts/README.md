# Fuentes locales

Para mantener la experiencia completamente local (sin CDN), coloca aqui las fuentes en formato WOFF2:

- WizardDisplay.woff2
- BookSerif.woff2
- InkHand.woff2

El proyecto ya tiene `@font-face` configurado para esas rutas en `app/globals.css`.

Recomendacion de familias para este proyecto:

- Display: fuente fantasy/wizarding con licencia libre para redistribucion
- Texto: serif editorial clasica
- Script: caligrafia de tinta legible

Importante:

- Verifica licencia antes de distribuir archivos de fuentes.
- Evita fuentes con uso personal-only si el proyecto se publicara.
